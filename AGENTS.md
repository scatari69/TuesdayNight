# TuesdayNight

Самостоятельный Discord-бот для сборов Deadlock и ролей по реакциям.
Python 3.11+, discord.py 2.x; интерфейс и комментарии на русском.
Делай минимальные полные изменения, переиспользуй существующие функции.
Перед исправлением находи вызовы через `rg`, обновляй связанные тесты и README.
Состояние меняй через `Store.edit`, читай через `Store.read`; сохраняй
атомарную запись, изоляцию серверов, таймауты и обработку ошибок.
Не коммить токены, `.env` и пользовательские данные.

- `bot.py`: discord.Client, slash-команды, persistent-кнопки, расписание,
  reaction roles. При добавлении команды обновляй `register_commands` и README.
- `state.py`: JSON-хранилище по guild ID, атомарная запись, чистые функции.
  Пользователи, роли и сообщения идентифицируются Discord ID. Состав не сохранять:
  брать из участников настроенной роли с Members Intent.
- `deadlock.py`: адаптированные HTTP-функции исходного проекта без Telegram;
  сохранить таймауты и кэши. Закрывать aiohttp-сессию вместе с клиентом.
- `test_bot.py`: unittest и AsyncMock; запуск из корня:
  `python -m unittest discover -s . -v`.
- Конфиг и контейнер самостоятельные; не добавлять aiogram в зависимости.
- Reaction roles: проверять права настройщика, иерархию, запрет @everyone,
  managed-ролей и ролей с разрешениями. Повторять проверку роли при событии.
- Ответы и пользовательский текст по умолчанию не должны пинговать роли/всех;
  разрешать только явные упоминания участников при сборе.
- Тесты не должны запускать Discord Client, реальные HTTP-запросы или читать
  рабочее состояние. Для интеграции нужен отдельный тестовый Discord-сервер.
